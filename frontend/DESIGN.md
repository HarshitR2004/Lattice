# Lattice — work in one continuous conversation

Concept: scientific precision with a quietly expressive voice. The signature is a violet-and-yellow waveform set inside a procedure-aware illustrative conversation. Alternatives considered were a document-led editorial layout and a full-screen molecular visualization; the instrument concept best explains the hands-free product without obscuring the message.

Typography: self-hosted Inter Variable; fluid, tightly tracked display text, readable body measures, small instrument labels. Midnight black #030303 grounds the page, electric violet #5245F8 defines controls and voice visuals, and sun yellow #F9B318 highlights the headline and deviation indicators. Elevated surfaces use neutral near-black tones; primary text is #F7F6FA and secondary text is #AAA7B5. Light violet tints keep small accent text readable.

Composition: asymmetric hero; centered problem story and split comparison; three procedural capability cards; five equally emphasized use-case cards; connected workflow; minimal footer. Mobile recomposes as a single column with vertical workflow steps. No prominent CTAs or contact links per user preference.

Motion: subtle waveform transforms and opacity, shared-layout scenario indicator, restrained hover lift, workflow opacity on entry. The waveform pauses offscreen and has pause/replay controls. Reduced motion removes nonessential animation. There is no microphone, audio output, backend, upload handling, or network product service.

Watermelon Continuous Tabs is adapted locally with Radix tab semantics; see THIRD_PARTY_NOTICES.md. Button composition follows shadcn/ui. No dashboard template, 3D runtime, page loader, artificial metrics, or invented customer proof.

Validation uses the local Vite development server. No production build or deployment is requested.
